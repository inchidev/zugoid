# Zugoid 0.3.0

- **A VPS Server updates from its Settings.** The Owner chooses a newer release in **Server settings → Deployment → Updates** and selects **Back up and update**, as on a Cloudflare Server. A small updater the VPS installer adds to the host runs the same verified upgrade as `zugoid upgrade`, with its mandatory backup and rollback, and Settings shows how it goes. Nothing installs on its own. A Server installed before 0.3.0 gets the updater with one `sudo zugoid upgrade`; after that, no terminal is needed.
- **A Server bought on zugoid.ru asks zugoid.ru.** Its update check and `zugoid upgrade` ask zugoid.ru whether it is covered, when the installer was run with `ZUGOID_SITE=https://zugoid.ru`. Only zugoid.com and zugoid.ru are ever asked.

# Zugoid 0.2.0

- **Business Source License 1.1.** Read, change and build Zugoid, and use it free for development and testing. A Server in production is free for its first 30 days and then needs its own subscription, one flat price per Server whatever it holds; see [Pricing](https://zugoid.com/pricing). A Server without a subscription keeps working; zugoid.com just offers it no new releases.
- **Customers.** Contacts and Companies, with mail as their first Source: a conversation with someone outside the Server lands in Customers, not in Chat. Put a chat on your website with a Customers Widget.
- **Appearance.** Settings → Appearance sets the accent, font and sign-in background, can show the Server's own name instead of Zugoid in the page, its title and its app manifest, hides the sidebar sections a Server does not need, and lists the sites allowed to show the Server in a frame.
- **Partner Servers.** A platform that makes Servers for its people can sign them in without a password and take them out again.
- **Calls on your own LiveKit.** Point the Server at a LiveKit you run, for example next to your people, and calls need neither RealtimeKit nor Cloudflare.
- **More Git providers.** GitLab, and Forgejo or Codeberg through the Gitea connection.
- **Faster first request on Cloudflare.** A release now ships the Server's modules as they are, and the installer uploads them, so a cold Worker compiles only what a request needs.
- **Fresh Servers only.** The Server schema starts again from one baseline. A Server installed from 0.1.x cannot be updated to 0.2.0; create a new one from zugoid.com/create.

# Zugoid 0.3.1

- **Telegram in Customers.** Connect a bot from BotFather in **Customers → Telegram**. Everyone who writes to it becomes a Contact verified by Telegram, and each Conversation opens in Customers. Telegram calls the Server, or the Server asks Telegram when it has no public address, as on a local network. If the Server cannot reach Telegram, point it at your own Bot API server or a proxy.
- **Conversations look like Chat.** A Widget or Telegram Conversation uses Chat's message list and composer and updates live. **Reply** goes to the customer and shows whether it was delivered. **Internal note** stays with the team. A delivered reply can't be edited or deleted. Email keeps its own view.
- **Pictures, voice and video.** Visitors send pictures and voice messages through the Widget, and video messages through Telegram. The team answers with text, pictures or a voice message.
- **Safer updates for Servers with data.** Allowed values such as statuses and kinds are now checked in code rather than in the database. A future release can add one without rebuilding tables. This update rebuilds them once, and keeps every row while doing so.

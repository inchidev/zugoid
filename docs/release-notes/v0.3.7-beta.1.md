# Zugoid 0.3.7-beta.1

- **Apps.** Open published Apps inside Zugoid and preview drafts with your existing Data access. App managers can publish a checked Project build while preserving Role grants.
- **Factory Builds.** Configured Artifacts projects run checks in Lizard against a specific commit when Zugoid publishes a branch, merges it or tags a Version. The Project shows build status, logs and Preview links. Destinations are Zugoid Apps and the Unot heavy game pilot.

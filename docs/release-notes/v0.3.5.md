# Zugoid 0.3.5

- **Tasks.** New Tasks start in Backlog. Set an assignee independently of status. Use In progress between Ready and Review on the Board or through MCP.
- **Google Gemini.** Connect Gemini directly as a model Provider, analyze public YouTube videos with timestamps, and use Nano Banana for images and avatars.
- **Agent research.** Configure integrations so Agents can search public posts on X and Threads, find Instagram posts by hashtag, and look up TikTok hashtag trends.
- **External Agents.** Connect and test Grok Bot and custom webhooks from the External agents section of Server settings.
- **Mail.** Refresh a folder and its unread counts in place, see one row per conversation in All mail, and quote selected text in a reply. Incoming email folds recognized quoted history.
- **Navigation.** The sidebar adapts to shorter windows, More uses square tiles on phones, and icons-only navigation is available in User Settings.
- **Unot development studios.** Members can sign in with Unot from the studio login page. The studio Owner can choose which Agents use Unot Studio Games with credentials provisioned by Unot.

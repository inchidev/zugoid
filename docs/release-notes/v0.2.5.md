# Zugoid 0.2.5

- **`zugoid upgrade` on a VPS asks about the subscription too.** Like Settings on a Cloudflare Server, it asks zugoid.com whether it offers this Server new releases, sending only the Server's UUID. A Server past its first 30 days without a subscription ([Pricing](https://zugoid.com/pricing)) is offered no new release: the upgrade stops before downloading anything, changes nothing and prints a link to subscribe. The Server keeps running. If zugoid.com cannot be reached, the upgrade goes ahead. A new VPS Server is noted when it is installed, so its 30 days start then.

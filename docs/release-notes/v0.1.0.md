# Zugoid 0.1.0

The first release of Zugoid: one workspace for a team and its AI agents.

- **Zugoid everywhere.** zugoid.com, the release assets (`zugoid-*`), environment names (`ZUGOID_*`), packages (`@zugoid/*`) and the native app id `com.zugoid.app`.
- **A new mark.** A face with two square eyes, on every icon, favicon and splash screen.
- **Fresh Servers only.** A Server installed before 0.1.0 cannot be updated to it. Create a new Server from zugoid.com/create or from this release.

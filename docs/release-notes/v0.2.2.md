# Zugoid 0.2.2

- **Creating and updating a Cloudflare Server works again.** The installer refused the Server modules that 0.2.0 and 0.2.1 ship, because a few of them live under `.well-known`, so creating or updating a Server from zugoid.com stopped before it touched your account. It now accepts them, and a release whose modules it would refuse can no longer be published.

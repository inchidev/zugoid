# Zugoid 0.1.0

The first release of Zugoid: one workspace for a team and its AI agents, now open source under the Apache License 2.0.

- **Zugoid everywhere.** zugoid.com, the release assets (`zugoid-*`), environment names (`ZUGOID_*`), packages (`@zugoid/*`) and the native app id `com.zugoid.app`.
- **A new mark.** A face with two square eyes, on every icon, favicon and splash screen.
- **Apache License 2.0.** Use, change, run and redistribute Zugoid under its terms. The license does not grant use of the Zugoid name or marks. Versions published earlier under the Elastic License 2.0 or the MIT License stay under those licenses.
- **Fresh Servers only.** A Server installed before 0.1.0 cannot be updated to it. Create a new Server from zugoid.com/create or from this release.

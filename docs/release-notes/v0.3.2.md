# Zugoid 0.3.2

- **Media.** A library of photos and videos for the whole Space. Upload files or a folder and browse them on a timeline by date, and share what you want with the team. Each Space's pictures live in the Server's private file storage.
- **Mail in Conversations.** Email threads open in the same Conversation pane as Widget and Telegram: one message list and one composer, live. A reply goes out from the mailbox, an internal note stays with the team, and inbound mail reaches an open Conversation as it arrives. The Mail page keeps folders, search, drafts and composing anew.
- **Modules.** The Owner turns modules off in Server settings → Modules. A module turned off leaves the sidebar and its API answers 404, while its data stays for when it returns.
- **Workers AI today.** The model list follows Cloudflare's live catalog after its November cuts, and the default agent model is GLM 5.3. In the deployment's model picker one click selects one model, with Select all and Deselect all beside the list.
- **An Agent knows its name.** A Run tells the model the Agent's own name, so an agent answers with the name it was given.

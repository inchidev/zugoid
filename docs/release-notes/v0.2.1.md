# Zugoid 0.2.1

- **Updates say whether your Server is covered.** **Server settings → Deployment → Updates** asks zugoid.com whether it offers this Server new releases. A Server is free for its first 30 days and then needs its own subscription ([Pricing](https://zugoid.com/pricing)). The page says until when a new Server gets releases. A Server without a subscription is offered no new release and gets a link to subscribe; it keeps working as it is. The check sends only the Server's UUID, and if zugoid.com cannot be reached every release stays on offer. A partner's Server gets its releases from its partner's platform.

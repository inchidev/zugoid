# Zugoid 0.3.3

- **Partner project links.** A partner sign-in can open the intended Project after sign-in and onboarding. User Settings show the partner name for an Account linked to a named partner.
- **Web search through OpenRouter.** Agents can use OpenRouter’s updated web search tool, with links supplied by the provider.
- **Scheduled.** Recurring schedules can keep a dedicated conversation. Agents can propose a recurring schedule from chat, and Servers can turn Scheduled off independently in Modules.
- **Cloudflare access.** The Server reports when its request for Cloudflare access was declined.
